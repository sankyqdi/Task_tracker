# 💻 Task Tracker (CLI)

[![Task Tracker CLI](https://img.shields.io/badge/Task_Tracker-CLI-2ea44f?style=for-the-badge&logo=java&logoColor=white)](https://github.com/sankyqdi/Task_tracker)

---

## 📌 О проекте

**Task Tracker CLI** — это консольное приложение для эффективного управления задачами и трекинга процессов. 

Проект разрабатывался как фундаментальная база для отработки чистой многослойной архитектуры (Layered Architecture), ООП-принципов и эффективной работы с коллекциями на Java, ставшей основой для дальнейшей эволюции в полноценный REST API сервис.

---

## 🛠 Технологический стек

* **Language:** Java 17+ / 21
* **Architecture:** Layered Architecture (Controller — Service — Repository)
* **Build Tool:** Gradle / Maven
* **Testing:** JUnit 5, Mockito
* **Data Storage:** In-Memory / File Storage

---

## 💡 Основной функционал и свойства

- [x] Разделение на четкие архитектурные слои (разделение ответственности)
- [x] Создание, редактирование, просмотр и удаление задач
- [x] Изменение статусов и приоритетов выполнения
- [x] Обработка пользовательского ввода через командную строку (CLI)
- [x] Базовая валидация данных и обработка консольных ошибок
- [ ] Покрытие бизнес-логики юнит-тестами (JUnit 5)
- [ ] Добавление сохранения состояния задач в файл (JSON/CSV)

---

## 🎯 Текущий статус разработки

> ⚙️ **Статус проекта:** Проект завершен в качестве консольного решения (CLI) и служит базовым архитектурным фундаментом. Основной вектор развития перенесен в веб-версию (REST API).
