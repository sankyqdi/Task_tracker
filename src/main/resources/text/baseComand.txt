📝 /add - СОЗДАНИЕ НОВОЙ ЗАДАЧИ

    Синтаксис: /add

    Обязательные поля:
    ─────────────────────────────────────────────────────────────────────
    • name                - Название задачи (строка, обязательно)
    • body                - Описание цели/суть задачи (текст, обязательно)
    • importanceLevel     - Уровень важности (1-10, обязательно)
                          ⓘ 1-3: Низкий, 4-6: Средний, 7-10: Высокий
    • stage               - Стадия выполнения (обязательно)
                          ⓘ Примеры: "TO_DO", "IN_PROGRESS", "REVIEW", "DONE"
    • dueDate             - Срок выполнения (YYYY-MM-DD, обязательно)
                          ⓘ Формат: 2026-07-15

    Опциональные поля:
    ─────────────────────────────────────────────────────────────────────
    • priority            - Приоритет (1-10, по умолчанию = importanceLevel)
    • tags                - Теги для категоризации
                          ⓘ Встроенные: BUG, FEATURE, ENHANCEMENT, DOCUMENTATION
                                       REFACTORING, TESTING, PERFORMANCE, SECURITY
                                       URGENT, BLOCKED, REVIEW, DEPLOYMENT
                                       BACKEND, FRONTEND, DEVOPS
                          ⓘ Кастомные: любые строки через запятую

    Примечание: Если срок не указан корректно, будет взят текущий год

👀 /show - ПРОСМОТР ЗАДАЧ

    Синтаксис: /show [ПРЕФИКС] [ПАРАМЕТР]

    ╔═══════════════════════════════════════════════════════════════════════╗
    ║  ПРЕФИКС  │ НАЗНАЧЕНИЕ           │ ПАРАМЕТР    │ ПРИМЕР              ║
    ╠═══════════════════════════════════════════════════════════════════════╣
    ║  (нет)    │ Последние задачи     │ -           │ /show               ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║  -a       │ Все задачи           │ -           │ /show -a            ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║  -i       │ Задача по ID         │ <ID>        │ /show -i 5          ║
    ║           │                      │ (1-9)       │                     ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║  -in      │ Задача по названию   │ <NAME>      │ /show -in API       ║
    ║           │                      │ (текст)     │ /show -in Реализ API║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║  -l       │ Важные задачи        │ -           │ /show -l            ║
    ║           │ (уровень ≥ 6)        │             │                     ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║  -li      │ Задачи по уровню     │ <LEVEL>     │ /show -li 8         ║
    ║           │ важности             │ (1-10)      │                     ║
    ╚═══════════════════════════════════════════════════════════════════════╝

    ℹ️  Информация в каждой задаче:
        • ID (уникальный идентификатор)
        • Название и описание
        • Уровень важности и приоритет
        • Стадия выполнения
        • Теги (встроенные 🏷️ и кастомные 📌)
        • Дата создания и последнего обновления
        • Срок выполнения
        • Статус выполнения (✓ завершено / ○ не завершено)
        • Примерное время на выполнение (в часах)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✏️  /update - ИЗМЕНЕНИЕ ПОЛЕЙ ЗАДАЧИ

    Синтаксис: /update <ПРЕФИКС> <ID>

    ╔═══════════════════════════════════════════════════════════════════════╗
    ║ ПРЕФИКС │ ИЗМЕНЯЕМОЕ ПОЛЕ │ ПАРАМЕТР    │ ПРИМЕР                    ║
    ╠═══════════════════════════════════════════════════════════════════════╣
    ║   -s    │ Стадия           │ <STAGE>     │ /update -s 3              ║
    ║         │ выполнения       │ (текст)     │ → укажите новую стадию    ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║   -dt   │ Срок             │ <DATE>      │ /update -dt 5             ║
    ║         │ выполнения       │ (YYYY-MM-DD)│ → укажите новый срок      ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║   -p    │ Приоритет        │ <PRIORITY>  │ /update -p 2              ║
    ║         │                  │ (1-10)      │ → укажите приоритет       ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║   -c    │ Статус           │ <STATUS>    │ /update -c 1              ║
    ║         │ выполнения       │ (true/false)│ → true (завершено)/false  ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║   -t    │ Добавить теги    │ <TAGS>      │ /update -t 4              ║
    ║         │                  │ (BUG,FEATURE)│ → укажите теги через ,   ║
    ╚═══════════════════════════════════════════════════════════════════════╝

    ⚠️  Все операции требуют подтверждения перед выполнением!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🗑️  /delete - УДАЛЕНИЕ ЗАДАЧ

    Синтаксис: /delete <ПРЕФИКС> [ID]

    ╔═══════════════════════════════════════════════════════════════════════╗
    ║ ПРЕФИКС │ ДЕЙСТВИЕ                │ ПАРАМЕТР │ ПРИМЕР                ║
    ╠═══════════════════════════════════════════════════════════════════════╣
    ║   -a    │ Удалить все из памяти   │ -        │ /delete -a            ║
    ║         │ (⚠️ ВНИМАНИЕ: только    │          │ ⚠️ требует подтверждение
    ║         │ текущая сессия)         │          │                       ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║   -aR   │ Полное удаление всех    │ -        │ /delete -aR           ║
    ║         │ данных из хранилища     │          │ ❌ ОПАСНАЯ КОМАНДА    ║
    ║         │ (⚠️ НЕВОЗМОЖНО           │          │ ⚠️ требует подтверждение
    ║         │ ВОССТАНОВИТЬ)           │          │                       ║
    ╟───────────────────────────────────────────────────────────────────────╢
    ║   -i    │ Удалить из памяти       │ <ID>     │ /delete -i 5          ║
    ║         │ по ID                   │ (1-9)    │ ⚠️ требует подтверждение
    ╟───────────────────────────────────────────────────────────────────────╢
    ║   -iR   │ Полное удаление из      │ <ID>     │ /delete -iR 5         ║
    ║         │ хранилища по ID         │ (1-9)    │ ❌ ОПАСНАЯ КОМАНДА    ║
    ║         │ (⚠️ НЕВОЗМОЖНО           │          │ ⚠️ требует подтверждение
    ║         │ ВОССТАНОВИТЬ)           │          │                       ║
    ╚═══════════════════════════════════════════════════════════════════════╝

    ℹ️  Разница между удалением:
        • -a / -i   : удаляет из памяти текущей сессии
        • -aR / -iR : удаляет из постоянного хранилища (JSON файл)

💡 ПОЛЕЗНЫЕ СОВЕТЫ И ПРИМЕРЫ

    1️⃣  Создание задачи:
        /add
        name: Реализовать API
        body: Создать REST API для управления задачами
        importanceLevel: 8
        stage: IN_PROGRESS
        dueDate: 2026-07-15

    2️⃣  Просмотр всех высокоприоритетных задач:
        /show -l

    3️⃣  Поиск задачи по названию:
        /show -in Реализовать

    4️⃣  Изменение стадии:
        /update -s 5
        → укажите новую стадию: REVIEW

    5️⃣  Пометить задачу как завершенную:
        /update -c 5
        → укажите статус: true

    6️⃣  Добавить теги к задаче:
        /update -t 3
        → укажите теги: BUG, BACKEND, Spring Boot
